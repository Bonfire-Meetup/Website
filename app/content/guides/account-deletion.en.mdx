<Sections>

<Section title="Intent and confirm flow" icon="trash">

1. Open Account and go to the danger zone.
2. Confirm intent to start deletion.
3. Request the one-time deletion code.
4. Enter the code and confirm deletion.

</Section>

<Section title="One-time code details" icon="mail">

1. The deletion code is sent to your account email.
2. It is short-lived and can expire, so use it promptly.
3. If needed, request a new code and retry the confirmation step.

</Section>

<Section title="Permanence warning">

<Steps variant="rose-dot">

- Deletion cannot be undone.
- Your account data and related activity are removed.
- After deletion, you are redirected away from the account area.

</Steps>
